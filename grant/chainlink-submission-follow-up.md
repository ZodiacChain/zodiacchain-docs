## 2. Submitted Project Summary

ZodiacChain is a testnet-first verifiable draw infrastructure project focused on transparent, deterministic, and publicly auditable draw execution.

The MVP is designed to demonstrate how Chainlink VRF can provide verifiable randomness for draw resolution, while Chainlink Automation can support autonomous lifecycle execution for scheduled draw flows.

The current phase is limited to public documentation, technical demonstration, and testnet MVP readiness. It does not include real-money operations, mainnet launch, token presale, token issuance, or investment offering.
